# Перевод Rollboard

Rollboard читает тексты интерфейса из JSON-каталогов на диске на каждом запросе.
Новый язык — это положить файл и перезапустить: **без пересборки образа, без
перекомпиляции, без изменений в коде**.

В образе есть английский (`en`) и русский (`ru`).

## Добавить язык за три шага

### 1. Скопируйте существующий каталог

```bash
cp locales/en.json locales/de.json
```

Имя файла — это языковой тег, и он должен выглядеть как `de`, `pt-BR` или
`zh-Hans`. Всё остальное игнорируется.

### 2. Переведите значения

Ключи остаются английскими, меняются только значения.

```json
{
  "app.rooms": "Räume",
  "auth.tab.guest": "Gast"
}
```

Всё пропущенное берётся из английского, поэтому частичный перевод годится сразу.

### 3. Перезапустите приложение

```bash
docker compose restart app
```

Новый язык сам появится в переключателе. Больше ничего делать не нужно.

## Подстановки

Фигурные скобки подставляются при отрисовке и должны пережить перевод:

```json
"dashboard.welcome": "Willkommen, {name}. Entwürfe sind privat, bis du eine Version veröffentlichst."
```

Потерянная подстановка просто не появится, опечатка в ней будет напечатана
буквально. Тесты проверяют, что все языки используют те же подстановки, что и
английский.

## Формы множественного числа

Языки расходятся в том, сколько форм им нужно, поэтому количества — не пара
«единственное/множественное». Rollboard использует `Intl.PluralRules` и ищет
ключ `<ключ>.<категория>`.

Английскому нужны две:

```json
"playtest.playerCount.one": "{count} player",
"playtest.playerCount.other": "{count} players"
```

Русскому нужны три, потому что форма зависит от последних цифр — 1 игрок,
2 игрока, 5 игроков и снова 21 игрок:

```json
"playtest.playerCount.one": "{count} игрок",
"playtest.playerCount.few": "{count} игрока",
"playtest.playerCount.many": "{count} игроков",
"playtest.playerCount.other": "{count} игрока"
```

Используйте те категории, которые есть в вашем языке: `zero`, `one`, `two`,
`few`, `many`, `other`. Если не задать ни одной, для любого количества берётся
голый ключ — это верно для языков вроде японского, где числа не влияют на форму.

## Сообщения об ошибках

Бэкенд отвечает стабильным машинным кодом (`ACCOUNT_REQUIRED`,
`ROOM_MEMBERSHIP_REQUIRED` и так далее) вместе с английским текстом. Интерфейс
показывает `errors.<КОД>` из каталога и обращается к английскому тексту сервера
только тогда, когда встречает незнакомый код. Именно поэтому серверные
сообщения вообще переводимы: переводите ключи `errors.*`, а не сервер.

## Где лежат каталоги

| Контекст | Расположение |
|----------|--------------|
| Репозиторий | `locales/` |
| Контейнер | `/app/locales` |
| Переопределение | то, на что указывает `ROLLBOARD_LOCALES_DIR` |

**Монтирование заменяет каталог, а не дополняет его.** Если вы примонтируете
свои файлы поверх `/app/locales`, сначала скопируйте туда поставляемые, иначе
потеряете английский и русский:

```bash
docker run --rm --entrypoint sh ghcr.io/mirivlad/rollboard:latest \
  -c 'tar -c -C /app/locales .' | tar -x -C /srv/rollboard/locales
```

Английский дополнительно вкомпилирован в бандл фронтенда как последний рубеж,
поэтому отсутствующий или неверно настроенный каталог даёт читаемый английский
интерфейс, а не страницу голых ключей.

## Как выбирается язык

1. Язык, который игрок выбрал в прошлый раз, из `localStorage`.
2. Иначе лучшее совпадение с `Accept-Language` — `ru-RU` подходит к каталогу,
   опубликованному как `ru`.
3. Иначе английский.

## Как проверить перевод до отправки

```bash
cd frontend && npm test
```

Набор падает, если в языке нет ключа, который есть в английском, если есть
ключ, которого нет в английском, или если подстановки разошлись с английскими.
Добавьте свой язык в эти проверки в `frontend/src/lib/i18n.test.ts`, если хотите
его тоже покрыть.

## Как отправить перевод в проект

Откройте pull request, добавляющий `locales/<тег>.json`. Больше менять ничего не
нужно: ни конфигурацию сборки, ни компоненты, ни код.
